# Ver.50：呼称問題の正解音声

## 変更内容
- 「絵を見て名前を言う」で、マイク認識が正解した直後に「正解です。できました。」を日本語音声で自動読み上げします。
- 画面の判定表示も「正解です！できました！」に統一しました。
- 既存の成功音と音声設定を利用し、成功音声を二重に呼び出さないようにしました。
- index.html のスクリプト参照にキャッシュバスター v50 を設定しました。

## 音声について
読み上げはブラウザ標準の日本語音声合成（ja-JP）を使用します。音声設定がオフの場合はアプリ全体の設定に従って読み上げません。ブラウザ・端末によって利用できる日本語音声や声質が異なります。
