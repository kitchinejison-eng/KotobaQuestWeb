## GitHub Pagesへの反映
完全版ZIPの場合は、ZIP内のファイルとフォルダを `index.html` と同じルート階層に配置してください。
差し替え用ZIPの場合は、同名ファイルを同じ階層に上書きしてください。`images/ivent` 内の画像も合わせてアップロードしてください。

## 音声について
音声はブラウザの日本語音声合成（Web Speech API）を利用します。端末に日本語音声がある場合はそれを優先します。端末の音声設定やブラウザの制限によっては、初回の自動読み上げが始まらないことがあります。その場合は「🔊 もう一度聞く」を押して再生してください。
