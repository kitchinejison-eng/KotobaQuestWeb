# ことばクエスト Web V54

## 更新内容
- 発音トレーニングのマイク練習を追加し、音声認識されたテキストを表示します。
- 発音トレーニングの正解時に「正解です。できました。」を画面表示し、読み上げます。
- 発音トレーニングの既存記録・達成度・復習機能を維持します。

## GitHub Pages
このフォルダー内のファイル一式をリポジトリの公開ルートへ配置してください。マイク機能は HTTPS とブラウザーの音声認識対応が必要です。初回利用時はブラウザーのマイク許可を有効にしてください。

## 注意
音声認識は発話内容の文字起こしであり、子音・母音の調音精度を医学的に判定するものではありません。
