# ことばクエスト Ver.49 — GitHub Pages 用

## 公開に必要なもの
このZIPの中身を、GitHub Pagesを公開しているリポジトリのルートに置いてください。`index.html` がトップにある構成です。

## Ver.49 の更新点
- 「失語症のトレーニング｜絵を見て名前を言う」をマイク回答専用に変更
- 「できた」「自分で確認」ボタンと文字入力欄を呼称問題から削除
- 日本語音声認識の開始・聞き取り中表示・自動判定・再試行を改善
- ひらがな・カタカナ・漢字の表記ゆれと、認識候補を確認して判定
- マイク拒否、無音、マイク未検出、ネットワークエラー、非対応ブラウザを区別して案内
- マイク使用中にボタンの色・表示を切り替え、現在の状態を分かりやすく表示

## アップロード手順
1. ZIPを展開します。
2. 展開したフォルダの中身をリポジトリのルートへアップロードします。`index.html` が `index.html/index.html` のような入れ子にならないようにしてください。
3. GitHubのPages設定で、公開元のブランチ・フォルダが正しいことを確認します。
4. 公開後にブラウザを再読み込みします。反映されない場合は強制再読み込みを試してください。

## マイクの利用について
音声認識はブラウザの Web Speech API を使います。GitHub Pages のHTTPSページを、音声認識に対応した Google Chrome または Microsoft Edge で開き、ブラウザのマイク利用を許可してください。ネットワークや端末設定によっては音声認識サービスが利用できない場合があります。その場合は画面の案内に従い、接続・権限・マイクを確認してください。

## 確認事項
JavaScript構文、URLのキャッシュ更新、ZIPの整合性、呼称問題に「できた」「自分で確認」ボタンや文字入力欄が含まれないことを確認しています。実機のマイク音声認識は利用者の端末・ブラウザ・権限に依存するため、公開先でも確認してください。
