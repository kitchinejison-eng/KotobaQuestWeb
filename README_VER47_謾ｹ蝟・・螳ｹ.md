# ことばクエスト Ver.47 — 訓練問題・音声・UI改善

## 主な更新

- **脳トレ｜文字・画像マッチング**：31問。文字が写り込んだ写真や内容が一致しない写真を避け、文字なしの専用イラストを表示。絵カードには名前を表示せず、選択前に答えが見えない方式に変更。
- **脳トレ｜文字並べ替え**：30問。ばらばらの文字タイルを押して並べ、戻す・やり直す・答え合わせができます。不正解でも正解は表示しません。
- **脳トレ｜写字・見写し**：24問。見本を表示し、マウス・指・タッチペンで実際に書ける用紙型キャンバスへ変更。
- **脳トレ｜○×・意味理解**：30問。○／×の大きな選択ボタン。不正解でも答えをすぐに表示しません。
- **失語症のトレーニング｜身ぶり＋ことば**：20問。身ぶりや生活場面と一緒に使う言葉を選び、機能的な表現を練習します。自己申告の「できた」方式は廃止。
- **失語症のトレーニング｜生活の場面で伝える**：30場面の4択。買い物、カフェ、病院、駅、仕事や家庭での用件を想定し、場面に合う表現を選びます。
- **コトバ・ダンジョン**：操作、正解、不正解、ヒント、攻撃、開始、レベルアップに効果音を追加。BGMは利用者操作後に再生し、アプリのタブが非表示になったり閉じられたりしたときは停止します。
- **ことばファンタジーDX**：既存6問のヒントを見直し、生活で使う言葉や行動の25問を追加。導入時のキャラクターとセリフを毎回ランダムに変更。不正解時に正解を画面・音声で表示する処理も変更。
- 各更新ファイルにバージョン番号を付け、ブラウザの古いキャッシュが残りにくいようにしました。

## GitHub Pages への反映

### 完全版を使う場合
1. `KotobaQuestWeb_V47_GitHubPages.zip` を展開します。
2. 展開した**中身**（`index.html`、`app.js`、`images`、`BGM`など）をGitHubリポジトリのルートへアップロードします。ZIPの外側のフォルダごと入れ子にしないでください。
3. 既存ファイルを上書きする前に、現在の版をバックアップしてください。

### Ver.46 から差し替える場合
`KotobaQuestWeb_V47_差し替え用.zip` を展開し、ZIP内にあるファイルを同じ名前・同じ階層へ上書きします。既存の `images` や `BGM` は削除しないでください。Ver.47ではマッチング専用の `images/matching` フォルダが追加されているため、このフォルダもアップロードしてください。

## 確認状況・注意

- JavaScriptの構文チェック、問題数、4択の選択肢数、参照画像ファイルの存在を確認しています。
- 音声読み上げやマイク認識、タッチ操作は端末・ブラウザごとに挙動が異なります。公開後に実機で確認してください。
- 写字は手書き動作を練習する機能です。手書き文字を自動で読み取って採点するOCR機能は搭載していません。
- 失語症・高次脳機能障害の症状や得意な方法は個人差があります。訓練は本人の疲れやすさ・理解しやすさに合わせて、無理のない範囲で行ってください。
