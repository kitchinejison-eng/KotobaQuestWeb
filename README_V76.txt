【追加機能】
「構音筋ビジュアルナビゲーション」を新ジャンルとして追加し、ジャンル一覧の先頭に配置しました。

【練習の流れ】
1. 簡易図で、口の開き・唇・舌先・舌の奥・息の通り道のどこを意識するか確認します。
2. 画面上部または練習画面のお手本ボタンで音を聞きます。
3. マイクで声を出して練習し、音声認識の結果を確認します。
4. 次の課題へ進みます。

【注意】
図は位置を理解するための簡易イメージです。舌や唇の動きには個人差があり、音声認識も環境や発話によって誤認識することがあります。この機能は医学的な評価・診断を行うものではありません。痛みや疲労がある場合は無理をせず休憩してください。

Android版：app/src/main/assets/www/ にWeb画面のファイルを配置しています。
