# ことばクエスト Web版 V57

## 対象画面の修正
- 「絵を見て名前を言う」などのカスタム失語症画面で、前のトレーニングが残した `hidden` 状態を解除し、画像表示を復旧。
- 「聴覚的指差し・選択」は音声を聞き、文字名を見ずに絵カードから選ぶ画面に再構成。
- 「聴覚的指示」は正解の指示文を先に表示せず、音声で指示を聞き、動作カードを選ぶ画面に再構成。
- 「コミュニケーションボード」はアイコン・大きな言葉カード、選択状態、読み上げボタン、決定操作を備えたボードUIに再構成。
- 「穴埋め・自動言動」は文の空欄と選択肢を大きく表示し、誤っていたあいさつのヒントを修正。
- 「写字・見写し」は罫線を筆跡の下に描くようにし、線が見えやすいよう改善。消しゴムと1手戻す機能は維持。
- 文字並べ替えの不正解時は、不正解音・読み上げの後、自動で次の問題へ進む。
- WebView資産と共通コードを同期。

正誤音声は既存の共通処理を使用します。音声認識と読み上げは端末・ブラウザーの対応状況に依存します。
