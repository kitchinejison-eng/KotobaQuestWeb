# ことばクエスト V55 / Android 3.8.0

## 今回の修正
- 提供された「クイズ正解3.mp3」「クイズ不正解1.mp3」を共通の正解音・不正解音として登録。再生できない環境では従来の電子音へフォールバックします。
- 全ジャンルの正誤処理から、不正解時の「不正解です。」読み上げ、正解時の「正解です。できました。」読み上げを共通化。ことばダンジョンにも反映。
- 発音トレーニング全問題にマイク練習ボタン。マイク練習した問題名・認識テキスト・回数を記録し、結果画面にも問題別の成績を表示。
- 発音トレーニングの不正解時は約1.5秒後に次の問題へ進みます。
- 脳トレ「○×・意味理解」「文字・画像マッチング」「写字・見写し」の不正解時は次の問題へ自動で進みます。
- 写字に「書くモード」「消しゴムモード」「1手戻す」「全部消す」を追加。書けた／復習して次へを選べます。
- クレジットを追加：効果音：効果音ラボ、BGM：甘茶の音楽工房。

## マイクについて
音声認識で認識テキストを表示します。発音の調音精度を医学的・音響的に自動判定する機能ではありません。Web版はHTTPSと音声認識対応ブラウザー、Android版はマイク権限とOSの音声認識サービスが必要です。

## 配布
Web版の全ファイルをHTTPS対応のホスティング（例：GitHub Pages）へ配置してください。発音トレーニングのマイクはブラウザーの音声認識APIの対応状況に依存します。
