# ことばクエスト Ver.52 修正内容

## 今回の主な変更
- 「失語症のトレーニング｜生活の場面で伝える（4択）」は、最初に選んだ回答を採点します。
- 不正解時は正解を表示せず、不正解音を再生し、1.3秒後に次の問題へ自動で進みます。
- 回答中のヘッダーに「正解数／回答数・正答率」を表示します。
- 最終結果は正解数／出題数と正答率で表示します。
- 不正解音を短い下降2音にして、区別しやすくしました。
- 呼称・キューイングのマイク回答／文字入力で間違った場合にも、不正解音を追加しました。
- Android専用版Ver.51の変更は取り込まず、通常ブラウザ版Ver.50をベースにしています。

## GitHub Pagesへの更新
ZIPを展開し、中身をGitHub Pagesリポジトリのルート（`index.html` が置いてある場所）へアップロードしてください。既存ファイルと同名のものを上書きし、追加ファイル・画像フォルダがある場合は削除しないでください。

## 確認事項
JavaScriptの構文と、必要なファイルがZIPに含まれていることを確認しました。実機のスピーカー音量や音の聞こえ方は、利用するパソコン・ブラウザで確認してください。写字・見写しのような自由記述課題は、文字の正誤を自動採点しないため、不正解音の対象外です。
